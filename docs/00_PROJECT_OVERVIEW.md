# 00. 프로젝트 개요

## 핵심 가치 — 두 가지 영역

### 🧀 식탐정 스코어 (정적 평가, 100점 만점)
식당의 본질적 위생을 안정적으로 평가. 5단계 치즈 등급으로 시각화.

### 🌡️ 식탐정 위험 지수 (동적 가이드, 시간 단위 갱신)
오늘 이 시각의 외식·식중독 위험을 자치구 단위로 안내. 5단계 라벨 + 마스코트 의인화.

## 5축 점수 시스템 (총 100점)

| 평가 축 | 출처 | 배점 |
|---|---|---|
| A. 위생등급 | 식약처 음식점 위생등급 | +30 |
| B. 행정처분 | 서울시·자치구 행정처분 | -30 |
| C. 신뢰 인증 | 공공 인증 + 사장님 인증 | +25 |
| D. 리뷰 분석 | 자체 앱 + Google Places API | +30 |
| E. Gap 탐지 | 정적 인증 vs 동적 신호 | ±15 |

## Phase 0 핵심 의사결정 (잠금)

| 항목 | 결정 |
|---|---|
| 플랫폼 | 모바일 우선 반응형 PWA |
| 첫 화면 | 검색 (검색바 + 마스코트 위험 지수 카드) |
| 로그인 정책 | Soft Wall — 비로그인 95% 둘러보기 + 액션 시 소셜 1탭 |
| 사장님 모드 | 일반 가입 후 사업자 인증으로 모드 전환 |
| 권한 요청 | 위치=온보딩, 카메라=업로드 시점, 알림=v1.1 |
| 메뉴 가이드 | MVP는 자치구 단위 위험 지수, v1.1에서 식당별 미시 가이드 |

## 타깃 사용자

- **B2C Primary**: MZ세대 (20대 후반~40대 초반) — 위생 민감도 + SNS 공유
- **B2C Secondary**: 자녀 둔 부모, 시니어
- **B2B Primary**: 위생 관리에 자신 있는 영세·중소 자영업자 (위생등급 미취득 97%)

## 60초 First-run 시나리오

```
0~5초:   외부 앱(배민)에서 식당명 복사
5~8초:   식탐정 PWA 진입 → 클립보드 토스트 자동 감지
8~15초:  검색바 탭 → 자동완성에서 식당 선택
15~30초: 수사 보고서 진입 → 점수 + 골든 치즈 즉시 인지
30~60초: 5축 펼침 + sticky 외부앱 바에서 "배민 주문하기"
```
