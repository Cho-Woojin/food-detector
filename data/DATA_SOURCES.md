# 식탐정 데이터 출처 명세서

본 문서는 식탐정(food-detector) 프로젝트에서 식당 위생/안전 평가에 활용한 데이터의 공식 출처를 정리한 문서다. 같은 데이터가 여러 정부 사이트에서 제공되는 경우, **공공데이터포털 카탈로그 등록을 우선 출처로 표기**한다.

마지막 업데이트: 2026-05-09

---

## 📑 목차

| # | 출처 | 데이터셋 수 | 사용 |
|---|---|---|---|
| 1️⃣ | 공공데이터포털 (data.go.kr) | **6** | 식당 마스터 + 위생 시그널 + 안심식당 + 착한가격업소 |
| 2️⃣ | 식품안전나라 (식약처 자체 OpenAPI + 공지 Excel) | **2** | 행정처분 + 위생등급 3단계 (위생관리평가 I1540은 제거됨) |
| 3️⃣ | 새올전자민원창구 (서울 25개 자치구) | **25** | 자치구 행정처분 (위생직결 위반 보강용) |
| 4️⃣ | 서울 열린데이터광장 (data.seoul.go.kr) | **1** | 상권/인구 (확장 예정) |
| 5️⃣ | 카카오 (developers.kakao.com) | **3 API + 1 SDK** | 좌표 보강 + 신규 식당 + 지도 |
| **합계** | — | **37 데이터셋 + 1 SDK** | |

## 1️⃣ 공공데이터포털 (data.go.kr)

> 같은 데이터가 다른 정부 사이트(LOCALDATA, 식품안전나라)에서도 다운로드 가능하지만, **공공데이터포털에 카탈로그 등록된 데이터셋은 공식 출처를 공공데이터포털로 표기**.

### ① 전국일반음식점표준데이터 (`15096283`) ⭐ 식당 마스터

- **URL**: https://www.data.go.kr/data/15096283/standard.do
- **운영기관**: 행정안전부 (지방자치단체 통합)
- **한 줄**: 전국 자치단체 일반음식점 인허가 정보 통합 표준데이터
- **디테일**:
  - 다운로드 경로: LOCALDATA bulk (`07_24_04_P_CSV.zip`, 211MB) — `https://www.localdata.go.kr/datafile/each/07_24_04_P_CSV.zip` 직접 받기 가능
  - 압축해제 940MB / 서울 영업·정상 **120,762건** (2026-05-11 raw 재빌드)
  - 47개 컬럼: 관리번호, 사업장명, 인허가일자, 영업상태명, **상세영업상태명**, 폐업일자, 소재지·도로명 주소, 좌표(EPSG 5174), 업태구분명(한식/일식/중식 등), 소재지전화 등
  - **식탐정 식당 마스터의 베이스** — `scripts/rebuild-master-from-raw.js`로 "상세영업상태명 == 영업" + 소재지전체주소 prefix "서울"만 필터
  - 술 판매가 가능한 음식점
  - **⚠️ 시차 문제**: LOCALDATA의 "영업/폐업" 갱신이 식약처 처분 시점보다 수개월~수년 늦음. 본도시락 100건 등 식약처에서 "영업소폐쇄"인데 LOCALDATA에선 "영업" 케이스 다수 → `flags.suspectedClosed=true` 마킹으로 보완 (자세한 건 [SCORING_AND_SCHEMA.md](./SCORING_AND_SCHEMA.md)).

#### 지정 기준 (위생 평가 항목 포함, 100점 만점)

행정안전부 평가표 기준. 구청장이 현지실사 평가단을 구성해 평가, 합계 일정 점수 이상이면 지정.

| 영역 | 배점 | 세부 항목 |
|---|---|---|
| **가격** | 45 | 가격수준(지역 평균 미만) 20 / 가격안정 노력(최근 1년 인하 또는 6개월 동결, 물가상승률보다 낮은 인상) 15 / 저렴한 가격상품 비중 10 |
| **영업장 위생·청결** | **30** | 주방·매장·화장실 위생·청결 — **(아래 상세)** |
| 서비스 | (잔여) | 직원 친절도, 응대 |
| 공익 | (잔여) | 옥외가격표시제 준수, 원산지 표시 준수 |

**위생·청결 30점 세부 평가 항목** (식탐정에서 별도 위생 시그널로 활용 가능):
- 바닥 내수처리 및 수세 상태
- 배수시설 청결도
- 위생복·위생장갑·위생모·위생마스크 착용도
- 식탁·의자 정리도
- 행주 등 용도별 사용 (위생/조리 분리)
- 소독용품 비치 또는 손씻기 시설 설치
- 정수기 위생관리 수준
- 수세·소독·환기 관리 정도 (세척제, 에어타월 또는 위생종이 구비)
- 창고·벽·천장·환기·방충시설 청결관리

> 위생등급제(C004)와 평가 영역이 겹치는 부분이 있어 식탐정에서는 보조 위생 시그널로 활용 가능. 다만 평가 주체가 다름 (식약처 vs 자치구), 통과 기준도 다름 (90/85/80점 vs 가격 등 종합 평가).

> **위생모범업소 우대**: 식약처 위생모범업소(=모범음식점) 또는 위생등급 지정 식당이 가격 기준만 맞으면 우선 지정 가능 — 즉 `flags.hasModel` 또는 `flags.hygieneDesignated`인 식당에 `flags.goodPrice`까지 붙으면 모든 위생 시그널이 통과한 식당.

### ⑦ 서울 25개 자치구 새올전자민원창구 행정처분 공개 ⭐ ROTTEN 트리거 핵심

- **개요**: 서울 25개 자치구 각각의 새올전자민원창구 행정처분 공개 페이지에서 위반사유 raw 텍스트 수집
- **운영기관**: 각 자치구 (행정안전부 새올시스템)
- **URL 패턴**: 자치구별 다양 (예: `https://jongno.eminwon.seoul.kr`, `https://eminwon.gangnam.go.kr` 등)
- **호출 endpoint**: `POST /emwp/gov/mogaha/ntis/web/caf/mwwd/action/CafMwWdOpenAction.do` (인증키 불필요)
- **주요 파라미터**: `method=selectListAdmm` (목록), `method=selectAdmmDtl` (상세), `pageIndex`, `pageSize`
- **응답 컬럼** (상세): `업소명`, `소재지`, `처분사항`, `위반내용`, `위반사항`, `위반사유`, `법적근거`
- **데이터 한계**: 행정처분 공개는 일정 기간(보통 6~12개월) 후 자동 삭제. 누적 데이터 X, 현재 진행중인 처분만.
- **수집 결과 (2026-05-10)**:
  - 25개 자치구 합계 **3,734건** raw 수집
  - 비음식점(대부업·자판기·담배·건강기능식품판매업 등) ~2,300건 제외
  - **음식점 위생 직결 위반 38건** 발굴 (룰 매칭: 이물·바퀴·곰팡이·세균·대장균·살모넬라·유통기한·소비기한·식중독 등)
  - by-gu 매칭 성공: **30건** (이름+자치구, 보수적 매칭, 다중 후보 skip)

#### ⭐ 인허가번호 → LOCALDATA mgtno 정확 매칭 공식 (2026-05-12 발견)

새올민원 처분 공개 페이지에 **`인허가번호`** 필드가 있음 — 20자리 숫자. 이게 LOCALDATA `mgtno`와 1:1 매칭됨:

```
새올민원 인허가번호: 30700001012021000038  (20자리)
                    │└자치구┘└업종┘└년도┘└─일련번호──┘
                    └ 7자리 ┴ 3자리 ┴ 4자리 ┴── 6자리 ──┘

변환 공식:
  자치구(7) + '-' + 업종(3) + '-' + 연도(4) + '-' + parseInt(일련번호6).padStart(5,'0')
  → 3070000-101-2021-00038  = LOCALDATA mgtno
```

**검증 사례 (성북구 생활회관, 2026-04-21 금속이물)**:
- 새올민원 인허가번호: `30700001012021000038`
- 우리 by-gu mgtno: `3070000-101-2021-00038` ✅ 일치

**미해결 작업**: 우리 `data/violations-eminwon.json` raw는 이 필드를 수집 안 하고 있음 (`ids` 객체엔 `org_and_team_code`만 있고 인허가번호 누락). 향후 수집 스크립트에서 이 필드를 함께 가져와야 fuzzy 매칭 없이 정확 매칭 가능 — 본도시락 100건 같은 false positive 해결 가능.

다음 라운드 새올민원 재수집 시 페이지 HTML에서 `인허가번호` 필드 셀을 함께 파싱하도록 추가 필요.
- **부착 스크립트**: `scripts/apply-eminwon-violations.js` → `flags.hygieneViolation=true` + `flags.punishReasons` 갱신
- **점수 영향**: 직접 가산/감산 X. **ROTTEN 트리거에만 사용** (score < 50 + hygieneViolation=true).
